# پایان‌نامه بلاکچین

## 🚀 کامپایل سریع

فقط یک دستور:

```bash
./build_thesis.sh
```

## 📁 ساختار پروژه

```
Chain/
├── build_thesis.sh          ← اسکریپت اصلی (فقط این را استفاده کنید)
├── thesis_latex_sample/     ← فایل‌های LaTeX پایان‌نامه
│   ├── main.tex
│   ├── main.pdf            ← PDF خروجی
│   ├── chapter1.tex        ← فصل 1: مقدمه
│   ├── chapter2-1.tex      ← فصل 2: مروری بر ادبیات
│   ├── chapter2-2.tex
│   ├── chapter_architecture.tex   ← فصل 3: معماری
│   ├── chapter_results.tex        ← فصل 4: نتایج
│   ├── chapter_conclusion.tex     ← فصل 5: نتیجه‌گیری
│   ├── appendix1.tex       ← پیوست: کدهای Rust
│   └── MyReferences.bib    ← منابع بلاکچین
├── src/                     ← کد Rust بلاکچین
├── real_benchmark.py        ← بنچمارک واقعی (اجرای کد Rust)
└── real_benchmark_results.json ← نتایج بنچمارک
```

## 🔧 اسکریپت build_thesis.sh

این اسکریپت:
1. ✅ بسته‌های LaTeX مورد نیاز را نصب می‌کند
2. ✅ پایان‌نامه را کامپایل می‌کند (XeLaTeX + BibTeX)
3. ✅ PDF را باز می‌کند

## 📄 خروجی

پس از اجرا، PDF در این مسیر قرار می‌گیرد:

```
thesis_latex_sample/main.pdf
```

## 🎓 موضوع پایان‌نامه

**عنوان**: طراحی و بهینه‌سازی الگوریتم اجماع مقیاس‌پذیر برای سیستم‌های بلاکچین

**نویسنده**: سجاد خوش‌دونی فراهانی  
**استاد راهنما**: دکتر علی کمندی  
**دانشگاه**: تهران - دانشکده علوم مهندسی
